Project description and workflow: 

In this project, we aim to develop an MLP regression model to predict the median income for block group using California Housing dataset. We split the original dataset into 80% training data and 20% test data. Additionally, to understand and describe the dataset, we conducted descriptive data analysis by creating visualizations including histogram, density plots, box plots, scatter plots, and correlation matrix for each variable. 

For the MLP Regressor, we used ReLU as the activation function and set the hidden layer sizes to (10, 5). To evaluate the performance of the model, we computed cross-validation scores with multiple folds and visualized the result with a boxplot. Based on the prediction result, we also plotted the actual vs predicted data comparison for both the train and test dataset. Finally, we conducted hyperparameter tuning and compared three activation functions, including ReLU, tanh, and logistic.
